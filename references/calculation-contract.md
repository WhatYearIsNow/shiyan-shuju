# 计算内核契约

使用 `scripts/uncertainty.py` 或编写实验驱动时读取。内核提供可测试的数值行为；测量模型、仪器参数和课程口径仍须由当前材料确定。

## 模块与兼容入口

`scripts/labmath/` 分为 `numbers`（Decimal 与修约）、`measurement`（直接测量）、`analysis`（传递/拟合/逐差）、`bridge`（历史电桥模型）、`regression`（固定回归）。`scripts/uncertainty.py` 保留原 Python 导出和命令行入口，已有驱动可继续 `import uncertainty`。

| 功能 | 接口/子命令 | 适用范围 |
|---|---|---|
| 直接测量 | `direct_result` / `direct` | 均值、样本统计量、A/B 类分量及现有两种结果算法 |
| 修约 | `align_result` / `round` | 最终值和不确定度末位对齐 |
| 不相关传递 | `propagate_power`、`propagate_numeric` / `prop` | 幂律或局部数值偏导；协方差需另行处理 |
| 线性拟合 | `linear_fit` / `fit` | 未加权最小二乘；不能替代含 x 误差的拟合模型 |
| 对半逐差 | `successive_difference` / `diff` | 当前实现仅接受偶数点，保留全部输入 |
| 电阻箱/电桥 | `resistance_box_error`、`bridge_row` / `boxerr`、`bridge` | 显式核对等级表、档位、格数及误差解释后使用 |

需要具体参数时运行 `python scripts/uncertainty.py <子命令> --help`。从脚本导入时将本 skill 的 `scripts/` 加入模块搜索路径；不要依赖用户的当前工作目录恰好等于 skill 目录。

## 输入、单位与精度

- 原始值用字符串，如 `"1.00"`，保留记录末位；不要先转二进制浮点再试图恢复有效数字。`D` 拒绝非数字、NaN 和无穷。
- 数学函数不管理单位。驱动中明确每个量的单位与换算，代入前统一；平方量和平方根的单位也要复核。
- 百分数必须写明语义：`0.005%` 与比例 `0.005` 不相同。电阻箱 `grades` 的准确度按百分数输入。
- 内核公有计算使用隔离的 60 位 Decimal 上下文，不修改调用方精度或输出流；改变调用方 `getcontext()` 不会覆盖这个固定工作精度。驱动的自定义运算也要显式管理局部精度，并检查敏感计算的稳定性；60 位不是所有模型都精确的保证。仅在最终展示修约，精确常数不限制测量值的有效位数。
- `fmt(x)` 会去掉小数尾零，`fmt(x, nd)` 固定小数位；最终结果用 `fmt_exact` 保留修约末位。
- `align_result(..., u_sig="auto")` 保留历史报告策略：按未修约不确定度首位 1/2 选两位、其他选一位；若原一位修约跨数量级，则保留进位前的末位，例如 `0.955` 展示为 `1.0`。因此 `auto` 不能承诺始终严格一位有效数字。材料明确指定一位/两位时传 `1`/`2`，其跨数量级结果仍须严格满足指定位数。修约使用 `ROUND_HALF_EVEN`。
- `add_sub` 对带符号项求和；旧名 `mul_div` 目前只连乘。除法在驱动中显式实现，不推断调用者意图。

## 数学结果与不确定度解释

重复测量的标准差与均值标准差不是同一个量；独立、同条件重复测量的均值标准不确定度可由均值标准差估计。[NIST：A 类评定](https://physics.nist.gov/cuu/Uncertainty/typea.html)

误差限 Δ 不自动等于标准不确定度 u。`type_b(delta, C)` 只执行 `delta/C`，分布和因数需由材料给定；均匀分布半宽 Δ 对应 `Δ/√3`，校准证书给出的扩展不确定度则要按证书覆盖因子换算。[NIST：B 类评定](https://physics.nist.gov/cuu/Uncertainty/typeb.html)

`combine` 及现有传递函数采用不相关分量的平方合成；共享仪器、共同校准参数或重复使用同一测量值时须检查相关性。有协方差时在驱动中按确认的模型实现，不因函数可算就省去相关项；数值偏导还须检查定义域和步长稳定性。[NIST：分量合成](https://physics.nist.gov/cuu/Uncertainty/combination.html)

扩展不确定度可写为 `U=k·uc`，但 `k=2` 本身不能保证精确 95% 覆盖。报告应记录 k、其选择依据及已确认的分布/自由度条件；条件不足时只写所用 k，不凭默认值附上“95%”。[NIST：扩展不确定度与覆盖因子](https://physics.nist.gov/cuu/Uncertainty/coverage.html)

### 必须显式识别的历史算法

- `direct_result(algo=1)` 默认给出 `U=2·uc`，返回 `method="course_k2"`。这是保留的结果算法；需要其他 k 时在驱动中显式计算，并同步展示说明。
- `algo=2` 保留课程形式 `U=√((t·S_mean)²+uB²)`，返回 `method="course_t_rss"`；它不是 `t·uc`，也不是通用有效自由度算法。只有本次材料采用此式时使用；内置 t 表仅覆盖双侧 95%、自由度 1–20，其他情况显式给 t 并记录来源。`conf`/`t_probability` 是选 t 的概率参数，不是最终区间覆盖率。
- `bridge_row` 中名为 `uB` 的返回字段沿用历史课堂记号，以误差限分量平方合成，返回 `method="course_bridge_rss"`；变量名称不能证明其已经变成标准不确定度。需要区分误差限、标准不确定度和扩展不确定度，不能直接将该字段套进其他统计模型。
- 上述结果返回 `coverage_probability=None`，表示软件未保证最终区间覆盖概率；不能将它改写为零，也不能用 t 表的 0.95 填充。
- 默认电阻箱等级表、常数项、档位数、偏转格数和灵敏阈是历史预设。每次调用都核实本次仪器与口径，不能把默认参数当作教师要求。

## 边界行为与恢复

| 输入情况 | 行为及解释 |
|---|---|
| 空数据、负误差限/不确定度、非正分布因数 | 报错，不自动取绝对值掩盖录入错误 |
| 单次测量有有效 B 类来源 | A 类未定义；可以按已知 B 类继续，不把 A 类写成“测得为零” |
| 单次测量且没有不确定度来源 | 可保留读数，不能宣称已完成不确定度评定 |
| 均值为零 | 绝对不确定度可计算；相对不确定度未定义 |
| 均值为负 | 相对不确定度以均值绝对值为分母 |
| 传入不确定度为零 | 保留值的书写末位；仍检查是否漏掉仪器分量 |
| 拟合长度不同、少于 3 对、x 全相同 | 报错，不截断、不补点；y 恒定时相关系数未定义 |
| 对半逐差奇数点、少于 2 点或 step 为零 | 报错，保留原始数据；待确认其他合法组织方式，不静默删末点 |
| 电阻箱超出位权表或最小步进 | 报错，不丢高位/小数位；核实真实量程和等级表 |

作图法、逐差法和拟合法是不同分析选择。教师要求图上取点时，可用拟合作核查；不得将拟合结果写成“手工作图得到”，或编造图上坐标。线性图写清横纵轴，例如纵轴 F、横轴 a 时斜率为 M，反过来为 `1/M`。

## 复算与证据

### 拟合参数的相关性

`linear_fit` 在原有返回值之外给出 `cov_ab`，单位为截距单位乘斜率单位；参数顺序为截距 a、斜率 b。在独立等方差残差模型下，`cov_ab = -xbar * sigma_y² / Sxx`。它与 `u_a/u_b` 一样只描述该拟合模型的参数统计量，不包含未知的仪器系统分量。[NIST：最小二乘及残差标准差](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd431.htm)

例如横轴截距 `q=-a/b` 的一阶方差为 `u_q²=u_a²/b²+a²*u_b²/b⁴-2*a*cov_ab/b³`。不能只用 `u_a/abs(b)`，也不能把 a、b 当作独立输入交给 `propagate_numeric`。该近似要求斜率远离零、局部线性化合理；接近零或不稳定时暂停这种区间表达，重新选择模型与区间方法。

在输出目录保存一个小型驱动或等价的可重算输入：包含全部原始值、来源 ID、单位换算、选用组、口径参数、公式和最终显示规则。输出未修约关键中间量及最终结果，确保每一个报告派生量都可复算。数值核查不能只比较两份共享同一错误公式的输出，还要检查量纲、极限/量级和可用的独立关系。

使用内核前运行 `python -B scripts/uncertainty.py selftest`；修改内核后运行仓库完整测试。自检数据是兼容基准，不是新实验输入。自检通过不等于原始值识别正确、课程口径已确认或 PDF 布局已验收。
