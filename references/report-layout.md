# 报告输出与版面验收

需要 `.tex` 或 PDF 时读取；只算数值时不要求 LaTeX、PDF、模板照片或个人信息。

## 选择产物

| 本次范围 | 交付 | 必要验收 |
|---|---|---|
| 只计算/解释 | 数值、公式、来源和未决项；复杂任务附复算驱动 | 全量复算、单位、修约、输入完整性 |
| TeX 源码 | 自包含 `.tex`、复算记录 | 同上；标明实际是否编译及有无视觉验证 |
| 最终 PDF | `.pdf`、可编辑 `.tex`、复算记录 | 数值检查、编译日志、全页渲染目视 |

用户提供的报告样式或已选课程 profile 决定版式。没有指定时，`assets/report-landscape.tex` 是可选的中性 A4 横向双框起点；个人栏留空，使用 `multicols*` 按左框→右框→下一页顺序填充，不在末页均衡双栏。模板 `bottom=34mm` 为右下角签字区留出正文空间。不要将学校专用抬头、固定姓名、某个实验列序或绝对路径加入通用模板。

## 生成规则

制作结果表、坐标图与图注时同时读取 [科研图表与数值表达](scientific-presentation.md)。先保留用户指定报告纸的尺寸、栏宽、页眉与签字区，再在可用区域安排三线表、规范量纲和可辨识的图形；样式规范不能替代原始读数与计算核验。

- 将模板复制为独立输出文件，在正文标记之间写内容；输出不依赖作者机器上的私人路径。只填写本次已提供且确实需要的个人字段。
- 表题、列序、符号与单位服从本次材料；正文先写符号公式，再写代入与结果。原始输入、未修约中间量和最终展示值分清。
- 中性双框模板默认纯文字、表格和公式；图像及原始记录通过追溯表引用。用户需要图形时按要求加入并重新验收，不能以模板默认限制用户的输出范围。
- 双栏表格用非浮动的 `tabular` 等结构，避免 `table` 导致漂移。宽表先调整列结构、合理换行或分表；确需缩放时目视确认字号仍可读，不以“没有溢出”代替可读性。
- 长公式优先用 `equation*` 加 `aligned` 分行；确认公式在实际栏宽内。避免写死某个旧模板的栏宽。
- 框内小标题沿用模板的小标题命令或同等字号；正文与框线、页眉及签字栏之间保持可见间隔。
- 双框中图、表与标题可组成不跨栏的小块，但整块必须短于实际栏高；先拆长表，再决定是否整体保持。`\raggedcolumns` 可避免双栏把段间空白强行拉大；小标题应与后文相连。不要仅靠强制留白命令控制双栏分页，需实测是否产生空页或孤行。
- 双栏末页默认不均衡，短正文可只占左框，不需要填满整页；自动均衡可能使短标题与正文分到左右两框。用户/profile 明确选择末页均衡时可以调整，仍须逐页确认标题、正文和签字区完整。
- 手工作图要求需要真实图及取点依据。没有图时交付可计算部分和待完成项，不绘制一张图再把软件拟合说成手工操作。
- 用户只要数据处理时不自动扩写实验目的、仪器介绍和操作步骤。分析讨论建议仅在请求/profile 包含时生成，逐条绑定实际数据，避免把相关性或误差大小写成已证明的因果。

## 编译与跨平台工具

中文 `ctexart` 模板使用 XeLaTeX；运行前检查引擎与所需宏包。数字内核不依赖 LaTeX。渲染可使用可用的 PyMuPDF 或 Poppler，不强制某种桌面工具或某个 PDF 阅读器 API。

保留实际编译日志。可以用 `rg`、Python 或本机原生命令检查 `.log` 中的 `Overfull`、缺字、缺包和致命错误；不要因为 Windows 没有 `grep` 就停止处理。TeX 编译通常需要多次才能稳定交叉引用，但重试应针对具体日志错误，不进行无差别重跑。

缺引擎或渲染器时交付已完成的计算/TeX，并明确 PDF 或视觉验证尚未完成；不声称完整验收，不用空 PDF 代替。不要在未请求的情况下安装大型工具链。

## 最终 PDF 门禁

1. **数值**：全部派生量由保存的输入复算；最终展示位数、单位和计算记录一致。报告审核再抽查代表行，覆盖每种公式。
2. **编译**：退出成功、无致命错误、无缺字或缺包，最终日志无未解决的 `Overfull`。`Underfull` 按实际版面评估，不能靠关闭警告伪造通过。
3. **全页渲染**：把最终 PDF 的每一页渲染并逐页查看，不仅检查首页或抽样。确认标题/信息栏完整，公式正确，表头与行列清楚，中文无乱码。
4. **边界**：文字不越框、不碰页眉，不压右下角签字栏；表格没有挤成难读小字，分页不丢表头或内容。
5. **留痕**：记录命令、工具版本或不可用情况、页数、日志/预览位置及实际验收结论。渲染图是 QA 文件，不必嵌入最终报告。

`Overfull=0` 是必要的日志检查，无法识别所有遮挡、字号或背景定位问题。任何 PDF 内容或模板坐标在验收后再改动，都应重新编译和检查受影响页面；最终交付必须对应最后一次实际查看的版本。

仓库 `scripts/check_template.py` 提供 `short`、`wide`、`multipage` 三种构造样例，用于检查短正文、宽表和多页流动。其日志与渲染文件支持模板回归；实际实验仍须对自己的最终 PDF 做全页视觉验收。
