# 私有课程配置示例

复制到 skill 的 `.local/profile.md` 后，填写你自己的课程资料位置；也可以把同样约定放在课程工作区 AGENTS.md。示例没有可用的真实测量值。

- 课程根：由当前工作区确定。
- 原始数据：`实验数据/MMDD-实验名/`。
- 课件与板书：`实验记录/images/MM-DD/`。
- 录音与逐字稿：`课程录音/`；已有时与书面材料双向提取，不为计算强制制造录音。
- 结果：`实验报告/`；驱动：`实验报告/计算/`；记录：`实验记录/`。
- 身份信息：本地 `报告纸信息.md`；公开模板默认留空，姓名不明时留空或在需要填写时确认。
- 模板：本地报告纸优先，其次用通用模板。说明课程名是否留空、允许嵌图与否。
- 课堂笔记：仅用户请求或本配置明确启用时调用可用技能，缺工具则记缺项。
- 历史实验预设：仅作索引；本次材料覆盖历史数值口径。
- 未决事项：逐项列出，不因来源优先级高就自动填成已确认。
