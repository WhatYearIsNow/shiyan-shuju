## 模板视觉验收

`python -B scripts/check_template.py --render` 编译3种合成样例：短正文1页、宽表/长公式1页、多页流动6页。共8页已逐页查看；最终日志无Overfull、缺字或致命错误，签字区与正文分离，表格及公式可读。

首次渲染实际发现短文末页均衡导致标题孤立、正文接近签字区；调整为通用模板顺序填栏和34mm底边距后重新渲染。工具输出的 `visual_review=pending` 是给每次实际使用者的人工步骤，不自动声称新报告已目视通过。

原始照片识别与OCR没有因为模板测试通过就得到验证；实际实验PDF仍须用自己的数据与全部页面再次验收。

## 行为场景

首轮使用的评估集包含3个构造文本任务（当前公开集已扩展为5个）：充分数据的直接测量、系数来源冲突但存在独立可算部分、9个有效逐差点且只要计算。执行者仅看到提示，评分断言分开保存；新旧版本分别执行，结果由独立评分者复核。评分摘要在完成后附于本报告。

这组场景只检验指令行为，样本很少；不用于证明普遍成功率、统计显著性或速度优势。未采集可靠的每场景token/耗时，因此不报告性能提升百分比。

## 发布与剩余范围

`check_release.py` 检查公开白名单、基本frontmatter、相对链接、常见身份/本机路径及私有排除项；检查属于启发式，不替代人工审查。`build_release.py` 在合成仓库验证了可重复ZIP、私有文件排除、错误时不覆盖已有输出与链接路径拒绝。

GitHub CI 已配置 Windows/Ubuntu × Python 3.10/3.12/3.14；本轮实际运行的三个解释器均为Python3.12系列；3.10/3.14及GitHub托管环境仍待CI验证。符号链接真实行为也需具备相应权限的环境验证。当前没有公开实际学生报告、教材、课件或原始扫描件。

模型仍局限于60位工作精度、一阶不相关传播、等权线性拟合及已标识的历史课程预设；不支持一般协方差、加权拟合或自动有效自由度。数值测试与流程场景都不能决定新的课程口径。

线性拟合另提供截距与斜率之间的 `cov_ab`；这不代表通用传递函数已经支持一般协方差矩阵。下游相关参数的传播仍需按明确模型实现。
