# 开源重构方案与验收

目标：将依赖私有课程资料的技能整理为可独立安装、可测试、可复算的公开项目，保留本地课程行为。此轮准备本地发布材料，不建立远端仓库或上传文件。

## 实施范围

1. 分层：`SKILL.md` 只存共享流程；`references/` 按需披露；`scripts/labmath/` 分离通用数学、课程电桥与CLI；旧入口保留。
2. 私有层：身份、绝对路径、课件、往届报告及其摘录不进入公开包；本地配置继续引用原课程包。历史材料中的数值冲突保留为待核，不能随迁移提升成通用规则。
3. 数值修复：独立复现修约进位、科学计数法、微小差分步长、Decimal 上下文、CLI键重复等问题，再增加回归与性质测试。
4. 工作流：计算、记录、TeX/PDF按需选择；缺失资料仅阻断依赖它的内容；数据来源、口径与方法假设明确。
5. 发布：MIT、中性模板、合成示例、贡献指南、白名单ZIP、相对链接与隐私检查、GitHub Actions。

## 验收标准

- 原有两套数值兼容基准通过；新增独立数学、边界、性质、CLI、发布工具及示例测试通过。
- 导入不改变调用方 Decimal 上下文与输出流；核心计算不依赖本机目录和第三方Python包。
- 公开包不含真实身份、绝对用户路径、私有档案或字节码；`.local/` 不进入ZIP。
- 通用报告模板完成短正文、宽表/长公式、多页三类编译与逐页渲染检查。
- 场景测试验证足够输入可计算、冲突不猜、奇数逐差不擅删；独立审阅保留实际输出。
- CI配置与实际运行结果分开报告；本机无法运行的环境不声称已验证。

本轮不实现OCR引擎、数据库、仪器自动采集、完整统计建模、自动上传或GitHub发布。后续优化以实际失败和用户反馈驱动。
